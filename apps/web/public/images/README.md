# 配图素材与授权

本目录下的每一张图都是**本项目自己生成的**，不包含任何第三方素材、他人软件界面截图、
真实品牌标识或他人商家名称。

## 三个目录

| 目录 | 数量 | 用途 | 制作方式 |
|---|---|---|---|
| `cases/` | 5 | 方案 PPT 的页型配图与主题封面（客厅落地窗 / 家庭影院 / 玄关感应灯 / 夜间卧室 / 餐厅吊灯） | 文生图生成真实摄影质感场景 |
| `agents/` | 13 | 13 个预置智能体的卡片封面（与各自职能对应） | 文生图生成真实摄影质感场景 |
| `tools/` | 20 | 智能百宝箱里 20 个工具卡的封面 | 自制的抽象示意图（几何图形与器物，不含任何界面文字） |

## 授权口径

- **没有一张来自图库、素材站或他人的产品**。
- 生成时的硬约束：画面内不得出现文字、字母、数字、logo、品牌名、水印、二维码、可识别人脸。
- 工具卡封面刻意做成**抽象示意图**而不是界面截图：界面截图必然带文字，
  而文生图生成的中文界面文字一定是乱码 —— 两条路都会产出「看起来像但其实是假的界面」。
- 设备名与房间名一律用通用描述（智能音箱 / 摄像头 / 恒温器 / 客厅 / 厨房），
  不使用任何真实产品型号。

## 换图时怎么做

页型配图可以在「页型配图」板块按租户替换（`PlanPageImage` 表，走
`PUT /api/plans/page-images/{pageType}`），门店可以换成自己的案例图。
本目录里的图只是**兜底默认值**。

## 曾经踩过的坑

- 初版 `tools/` 里混进了他人软件界面截图与真实品牌标识 —— 这类图**过不了开源合规**：
  仓库里出现别人的商标与界面，别人有权要求下架。
  视觉模型批量扫图（逐张问「图里有哪些文字和品牌名」）比人工翻图可靠，
  `check:brand` 只扫文本文件，扫不到图里的字。
- `materials/` 目录下的两张图是**零引用孤儿文件**（全仓无任何代码引用），
  已删除：没人用的素材只需要删掉，不需要「保留以备后用」。
